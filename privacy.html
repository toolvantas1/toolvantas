Privacy Policy

How Toolvantas handles local browser-side tool inputs, document files, aggregate web analytics, and voluntary support emails for visitors worldwide.

1. Local browser processing (Zero tool-input collection)

Toolvantas (https://toolvantas.pages.dev) provides browser-based calculators, converters, text utilities, developer encoders, and PDF tools for visitors worldwide. The website is built with static HTML, CSS, and client-side JavaScript, with no application backend database and no user account system.

  • When you enter numbers into calculators, paste text or developer payloads, build printable invoices, or select PDF files for merging, splitting, rotating, extracting, or page counting, all calculations and file operations execute locally in your browser's memory on your device.
  • Toolvantas does not upload, collect, store, or view your PDF files, invoice entries, financial figures, or text inputs.
  • Closing or reloading a page clears temporary in-memory inputs and generated download blobs from that browser tab.

2. Static website delivery (Cloudflare Pages)

Toolvantas is hosted and delivered globally over HTTPS through Cloudflare Pages. When your browser requests a webpage, stylesheet, script, or icon from https://toolvantas.pages.dev, Cloudflare routes the request across its edge network and processes standard network metadata (such as IP address and HTTP request headers) for content delivery and security in accordance with Cloudflare's privacy policy. Toolvantas does not maintain custom server logs or personal user account profiles.

3. Web analytics (Cloudflare Web Analytics), cookies & advertising

  • Cloudflare Web Analytics (Enabled): Toolvantas uses Cloudflare Web Analytics on Cloudflare Pages to measure aggregate website traffic, page views, referring websites, general country/region distribution, browser and device categories, and page-load performance (Core Web Vitals). Cloudflare Web Analytics is designed not to set client-side tracking cookies or use persistent browser storage to track individual visitors across websites, and it does not capture or read any numbers, text, invoices, or PDF files entered into Toolvantas tools.
  • Cookies & browser storage: The Toolvantas static HTML, CSS, and JavaScript files do not set first-party tracking cookies, advertising cookies, or persistent localStorage profiles, and require no sign-up or login.
  • Advertising status: No third-party display advertising networks are active in the current static release. If display advertising (such as Google AdSense) is enabled in the future, this Privacy Policy will be updated prior to activation to explain any applicable cookies, ad partners, and visitor controls.

4. Third-party script delivery on PDF tool pages (jsDelivr CDN)

Our five PDF tool pages (merge-pdf.html, split-pdf.html, rotate-pdf.html, extract-pdf-pages.html, and count-pdf-pages.html) load the open-source pdf-lib JavaScript library (v1.17.1) from the public jsDelivr CDN (cdn.jsdelivr.net). Opening one of those five pages causes your browser to fetch that static script file from jsDelivr under jsDelivr's privacy policy. Non-PDF pages on Toolvantas do not load external third-party scripts, and the PDF documents you open inside a PDF tool are never transmitted to jsDelivr.

5. Voluntary email correspondence

If you choose to email Toolvantas at toolvantas1@gmail.com, your email address and message contents are received via standard Gmail delivery and used solely to review and respond to your inquiry, feedback, or bug report. Please do not attach confidential PDFs, client contracts, or sensitive personal financial records when emailing support.

6. International visitors & separate projects

Toolvantas is accessible to visitors globally across modern desktop and mobile browsers and is operated as a standalone project without merging visitor metrics or correspondence with other websites. External third-party websites linked for reference operate under their own privacy policies.

7. Privacy contact

For questions about this Privacy Policy, email Toolvantas at toolvantas1@gmail.com or visit our Contact page.
