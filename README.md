Toolvantas

Free online tools for calculations, PDF documents, developer workflows, unit conversions, and everyday productivity.

Website: https://toolvantas.pages.dev/

Toolvantas is a static website built with HTML, CSS, and JavaScript. It provides 30 online tools organized into six categories, with a responsive interface designed for mobile and desktop browsers.

Tool Categories

- Freelance & Business: Hourly rates, freelance income, project pricing, profit margins, and invoice generation.
- PDF Tools: Merge, split, rotate, extract, and count PDF pages.
- Developer Tools: JSON formatting and validation, Base64 encoding, URL encoding, HTML entity encoding, and Unix timestamp conversion.
- Unit Converters: Length, weight, temperature, speed and running pace, and data storage conversions.
- Text & Productivity: Word counting, text case conversion, list deduplication, and regular-expression find and replace.
- Everyday Calculators: Percentages, age, business-day durations, shift hours, and discounts.

Browse the complete directory at https://toolvantas.pages.dev/tools.html.

Technology

- HTML
- CSS
- JavaScript
- Cloudflare Pages hosting
- Browser-based processing for supported tools

The website does not require a server-side application build process for its static HTML, CSS, and JavaScript files.

Repository Structure

Website files are maintained in the repository root.

- "index.html" — Homepage
- "tools.html" — Directory of all 30 tools
- "site.css" — Shared styles and responsive layout
- "site.js" — Shared website functionality
- "robots.txt" — Search-engine crawling instructions
- "sitemap.xml" — Sitemap for search-engine discovery
- "favicon.svg" — SVG site icon
- "privacy.html" — Privacy Policy
- "terms.html" — Terms of Use
- "contact.html" — Contact and support page
- Individual tool HTML files — Tool interfaces and functionality
- "PROJECT-STATUS.md" — Project continuation notes and historical planning

Deployment

Toolvantas is hosted on Cloudflare Pages at:

https://toolvantas.pages.dev/

The repository's "main" branch is used for website updates. When a change is committed, Cloudflare Pages should deploy it according to the project's configured deployment settings. Confirm the deployment status in Cloudflare before assuming a change is live.

Search Engine Files

- "robots.txt" identifies crawling instructions and the sitemap location.
- "sitemap.xml" lists website URLs for search-engine discovery.

Keep the sitemap and robots file aligned with the actual production domain. Verify any future domain changes before updating these files.

Privacy and Responsible Use

Supported calculators, text utilities, and PDF operations are designed to process user inputs locally in the browser. Refer to the Privacy Policy for the site's disclosures about hosting, analytics, and data handling.

Tool results are provided for general informational and planning purposes. Users should independently verify important calculations and outputs before relying on them.

Maintenance Guidelines

1. Preserve working tools and completed project work.
2. Make small, controlled changes instead of replacing unrelated files.
3. Test only the functionality affected by a change.
4. Confirm successful deployment before considering a website update live.
5. Keep Toolvantas separate from UtilityCanvas and AI Signal News.
6. Update this README when the site's architecture, deployment, or tool inventory changes.
