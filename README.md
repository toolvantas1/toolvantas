# Toolvantas

Free online tools for everyday tasks, calculations, and productivity.

## Simple upload workflow (mobile-friendly)

Upload the files in this ZIP directly to the root of the `toolvantas1/toolvantas` GitHub repository. **Do not upload this ZIP itself.** This package intentionally keeps all website files at the root, so you do not need to create folders or move files.

Files to upload:
- `index.html`
- `tools.html`
- `site.css`
- `site.js`
- `README.md`
- `PROJECT-STATUS.md`
- `robots.txt`
- `sitemap.xml`

The HTML pages load `site.css` and `site.js` from the repository root.

## Important
- The Freelance Hourly Rate Calculator is still marked as in development and is not functional yet.
- This is not deployed yet.
- `sitemap.xml` uses `example.invalid` as a placeholder. Replace it with the verified production URL before submitting a sitemap to search engines.
- Keep Toolvantas separate from UtilityCanvas and AI Signal News.
