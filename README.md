## Simple upload workflow (mobile-friendly)

Upload the **45 root website files** from `toolvantas-final-verified-v1.4.zip` directly to the root of the `toolvantas1/toolvantas` GitHub repository. **Do not upload a `.zip` archive file itself.** All HTML pages, `favicon.ico`, `favicon.svg`, `site.css`, `site.js`, `sitemap.xml`, and `robots.txt` sit flat at the repository root so no nested folders are required.

Review the remaining pending items in `privacy.html` (public release date) and `terms.html` (public release date and governing-law jurisdiction, intentionally left pending rather than defaulted to United States law), then remove the amber `.owner-flag` notice boxes once confirmed.
