How to permanently rotate PDF pages

Scanned documents often end up in mixed orientations, with landscape tables or inverted receipts scattered throughout a portrait report.

  • Rotate All Pages: Use "All +90°" or "All -90°" when an entire document was fed into a scanner sideways.
  • Rotate Individual Pages: Click the ↻ or ↺ buttons on specific page cards to adjust only misaligned pages without changing the rest of the document.
  • Odd/Even Batching: Easily fix duplex scanner flips where every alternating page is upside down.
  • Permanent Saving: The output file updates the native PDF rotation dictionary so it opens correctly in all PDF viewers.

Lossless rotation vs. image re-rasterization

Many basic online tools convert your PDF pages into bitmap images to rotate them, which causes blurry text, destroys selectable search text, and dramatically inflates file size.

  • Lossless Vector Editing: This tool modifies the underlying PDF /Rotate dictionary directly via pdf-lib.
  • Zero Quality Loss: High-resolution vector typography, embedded TrueType fonts, form fields, and links remain untouched.
  • Instant Client-Side Execution: No waiting for cloud uploads or server rendering queues.

Frequently asked questions

Does rotating a PDF reduce text or image quality?

No. Rotation is 100% lossless because it updates the native PDF /Rotate page dictionary without re-rasterizing or recompressing fonts and graphics.

Can I rotate only specific upside-down pages while leaving others intact?

Yes. Use the clockwise or counterclockwise buttons on any individual page card to rotate just that sheet.

Are my PDF documents uploaded to any server?

No. Your files are processed in-memory directly within your web browser using client-side JavaScript. No document data is sent to any remote server.

Is this rotation permanent when opened in Adobe Acrobat or browser viewers?

Yes. Orientation changes are saved into the downloaded PDF file itself so it opens upright in every standard PDF reader.

How do I fix duplex scans where every other page is upside down?

Click "Rotate Even Pages" or "Rotate Odd Pages" twice (for 180°) to flip alternating scanned sheets in a single batch.
