How to split PDF documents by page range

Splitting a PDF lets you isolate relevant pages from large records, reports, or ebooks without having to re-scan or recreate documents.

  • Single Pages: Enter individual numbers separated by commas (e.g. 1, 3, 5) to compile non-adjacent pages.
  • Page Spans: Use hyphens to define contiguous blocks (e.g. 2-8) to extract complete chapters or multi-page agreements.
  • Compound Selections: Combine ranges and single pages simultaneously (e.g. 1, 4-7, 10) to assemble custom document compilations.
  • Even Intervals: Use the "Split Every N Pages" mode to automatically batch invoices, checks, or statements into uniform subsets.

Why client-side PDF splitting guarantees privacy

Most online PDF tools upload your files to remote web servers where they sit in queues and are processed on shared cloud infrastructure. For financial audits, confidential proposals, and legal documentation, remote uploads introduce risk.

  • Zero Server Uploads: Processing takes place exclusively inside your browser's local sandbox memory using pdf-lib WebAssembly/JS.
  • Preserved Visual Fidelity: Extracting pages retains original fonts, embedded vector paths, high-resolution imagery, and exact layout coordinates.
  • No File Size Caps: Enjoy unrestricted splitting without being prompted to upgrade to a paid account.

Frequently asked questions

Are my PDF files uploaded to any server during splitting?

No. Your files are never uploaded to any external server. All page reading, splitting, and new document compilation runs locally inside your browser.

What format should I use for custom page ranges?

Use hyphens for spans and commas for multiple selections. For example, 1-3, 5, 8-10 extracts pages 1 through 3, page 5, and pages 8 through 10 into your new PDF.

Can I split a large PDF into individual 1-page documents?

Yes. Select "Split Every N Pages" and set the interval to 1. The tool generates a downloadable 1-page PDF for every page in the source file.

What happens if I enter an invalid page number?

The tool checks your input against the uploaded document's page count and displays an accessible validation message if a page is out of range.

Does splitting a PDF alter fonts or image resolution?

No. Pages are copied losslessly using native PDF object references, keeping original vector typography and embedded graphics intact.
